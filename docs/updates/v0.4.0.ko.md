# Jev Skill Router 0.4.0 업데이트

[English update notes](https://github.com/himomohi/jev-skill-router/blob/v0.4.0/docs/updates/v0.4.0.md)

요청 취소, 대규모 스킬 목록, 안전한 업데이트와 재현 가능한 검증을 강화했습니다. 실제 Jev 정확도·속도·요금 개선을 측정했다고 주장하지 않습니다.

## 주요 변경

- **MCP 요청 취소:** 진행 중인 HTTP·재시도 대기를 중단하고 대기 중 요청을 제거합니다. 라우팅 중에도 ping에 응답하며, 하나의 작업 스레드가 라우터 상태와 HTTP 연결을 관리합니다. 활성 요청을 포함해 최대 16개를 접수합니다. 취소된 요청은 결과를 보내지 않고, 종료 시 대기 작업과 연결을 정리합니다. 이미 공급자에게 전달된 요청은 과금될 수 있고 로컬 파일 작업은 단계 사이에서 취소를 확인합니다.
- **대규모 목록용 선택형 검색:** `candidate_strategy=indexed`와 `candidate_limit`을 추가했습니다. 이름·설명만 로컬 BM25로 검색한 뒤 Jev의 기존 판단·검증을 거칩니다. 평가 범위·잘린 후보·동점을 결과에 표시합니다. 기본값 `all`은 전체 목록을 평가하며, 후보 제한 이하의 작은 목록도 전체를 유지합니다. 검색 결과가 없으면 키 조회·API 호출 전에 중단합니다.
- **설정을 보존하는 업데이트:** `Install.py --upgrade`가 설치 버전을 확인하고 기존 설정 파일, 스킬 경로, 동작 모드, 자격 증명, 호스트 등록과 사용자 런처를 보존합니다. 기존 설정이 있으면 신규 설치 대신 업데이트를 안내합니다. 동일한 호스트 등록을 반복해도 설정을 다시 쓰지 않으며 충돌하는 항목은 보존합니다. Codex에는 환경 키의 이름만 전달하고 값은 저장하지 않습니다.
- **CLI 개선:** setup을 다시 실행해도 기존 모드를 유지합니다. 전환은 `--live`·`--offline`으로 명시합니다. `jev-skills --version`을 추가했습니다.
- **비교 평가:** 영어·한국어 96개 자체 작성 사례, 독립 BM25 기준선 두 개, 후보 유지율 측정, 전체 실행에 공통 요청 상한을 적용하는 실제 Jev 비교 도구를 추가했습니다. 사용자가 평가한 하네스 작업 결과도 출처를 명시해 가져올 수 있습니다.
- **실제 연결 확인:** 공식 MCP Python SDK 1.30.0의 stdio 왕복, Codex CLI 0.155.1과 Claude Code 2.1.278의 임시 프로필 등록·MCP 연결을 확인했습니다. 모델이 실제 작업을 완수한 검증과는 범위가 다릅니다.
- **배포 일치:** main 테스트를 통과한 커밋에서 wheel·sdist·소스 ZIP·SHA256SUMS를 생성합니다. 버전과 한영 변경 자료를 검사하고 기존 태그·파일을 덮어쓰지 않습니다. 중단된 초안은 기존 파일 바이트를 확인한 후 이어서 게시합니다.

## 기존 사용자 적용

새 소스를 내려받거나 체크아웃을 갱신한 폴더에서 실행하세요.

```bash
python Install.py --upgrade --non-interactive
# 환경 변수 인증만 사용하는 기본 설치는 --no-keychain을 추가합니다.
jev-skills --version
```

기존과 같은 `JEV_SKILLS_HOME`을 사용하고 호스트 세션을 다시 시작하세요. pip로 설치했다면 기존 Python 환경에서 `python -m pip install --upgrade '.[secure]'`를 실행합니다. 새 설정 항목은 기본값으로 적용되며 0.3.0의 첫 페이지·파일 digest 기반 이어 읽기는 유지됩니다.

대규모 목록의 후보 제한을 일회성으로 확인할 수 있습니다.

```bash
jev-skills plan "Inspect specialist operation" --candidate-strategy indexed --candidate-limit 64
```

검색에서 빠진 스킬은 뒤의 Jev 검증으로 복구할 수 없습니다. 전체 목록의 의미 기반 판단이 필요하면 `all`을 유지하세요. 16개 스킬의 자체 작성 사례에서 후보를 8개로 제한하면 필요한 스킬 92개 중 83개가 남았습니다. 이 수치는 Jev 정확도가 아닙니다.

## 검증 자료와 한계

- 합성 스킬 4,096개: 전체 평가의 기본 요청 상한은 58회여서 기본 32회 제한에 걸립니다. 후보 64개 검색에서는 같은 예제의 상한이 2회입니다. 실제 API 비용·지연을 측정한 결과는 아닙니다.
- 합성 200개 목록의 컨텍스트: UTF-8 바이트 58,088 → 4,940, 91.50% 감소입니다. 5개 목록에서는 오히려 27.28% 증가합니다. 모델 토큰·전체 대화·실제 요금 절감률이 아닙니다.
- 격리된 0.3.0 설치를 0.4.0으로 실제 업데이트했습니다. 설정 파일 바이트, offline 모드와 스킬 6개가 유지됐고 런처 버전도 확인했습니다. 키체인·API는 사용하지 않았습니다.
- 로컬 기준선의 정답 집합 일치: BM25 top-1은 60/96, threshold는 53/96입니다. 실제 Jev 결과는 아직 없으며 독립 검증 데이터도 아닙니다.
