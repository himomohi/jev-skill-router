# Jev Skill Router 0.4.1 업데이트

[English](https://github.com/himomohi/jev-skill-router/blob/v0.4.1/docs/updates/v0.4.1.md)

[0.4.0의 개선 사항](https://github.com/himomohi/jev-skill-router/blob/v0.4.1/docs/updates/v0.4.0.ko.md)을 포함하는 게시용 패치 버전입니다. MCP 요청 취소, 선택형 메타데이터 검색, 설정 보존 업데이트, 공식 SDK·실제 호스트 연결 검증과 영어·한국어 96개 비교 평가를 담았습니다.

0.4.0은 네 CI 환경을 통과했고 릴리스 파일 업로드도 완료했습니다. 다만 GitHub의 태그 조회가 게시된 릴리스만 반환해 새 초안을 찾지 못하면서 마지막 게시 단계가 중단됐습니다. 0.4.1은 인증된 목록에서 초안을 찾고 숫자 ID로 최신 파일 상태를 확인하도록 수정했습니다. 페이지 처리, 중복 초안, 조회 실패와 도중에 바뀐 항목을 검사하는 회귀 테스트도 추가했습니다.

기존 태그·파일은 보존했습니다. 공개되지 않은 0.4.0 초안은 그대로 두며, 다운로드는 **0.4.1 릴리스 파일**을 사용하세요.

소스 ZIP을 풀고 기존 설치를 업데이트합니다.

```bash
python Install.py --upgrade --non-interactive
jev-skills --version
```

기존과 같은 `JEV_SKILLS_HOME`을 사용하세요. 환경 변수 인증만 쓰는 기본 설치는 `--no-keychain`을 추가합니다. pip 설치는 기존 환경에서 `python -m pip install --upgrade '.[secure]'`를 실행합니다. 이후 호스트 세션을 다시 시작하세요. 전체 목록 평가 기본값을 포함한 기존 라우팅 설정은 유지됩니다.

테스트를 통과한 커밋에서 wheel·sdist·전체 소스 ZIP·SHA256SUMS를 생성합니다. 이번 패치는 배포 처리와 버전을 수정하며 라우팅 동작은 0.4.0과 같습니다. 실제 Jev 정확도·청구 요금과 모델을 사용한 하네스 작업 성공률은 여전히 미측정입니다.
