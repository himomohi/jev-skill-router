# Jev Skill Router 0.4.1

[한국어](https://github.com/himomohi/jev-skill-router/blob/v0.4.1/docs/updates/v0.4.1.ko.md)

The published maintenance version of the [0.4.0 improvement set](https://github.com/himomohi/jev-skill-router/blob/v0.4.1/docs/updates/v0.4.0.md): MCP cancellation, opt-in metadata retrieval, safe upgrades, official SDK/host connection checks and the 96-case EN/KO comparison suite.

The four-platform 0.4.0 Tests run passed. Its release assets uploaded successfully, but final publication stopped because the GitHub tag lookup returns published releases only and could not find the new draft. Version 0.4.1 fixes authenticated draft discovery and fresh asset inspection, with regression tests for pagination, duplicate drafts, failed reads and changed records. Existing tags and files are preserved. The unlisted 0.4.0 draft remains unchanged; use the 0.4.1 release assets.

From this release's extracted source ZIP, upgrade an existing guided installation:

```bash
python Install.py --upgrade --non-interactive
jev-skills --version
```

Use the same `JEV_SKILLS_HOME`; add `--no-keychain` for core-only installations using environment credentials. Pip-managed installations can use `python -m pip install --upgrade '.[secure]'` in their existing environment. Restart the host session. Existing routing configuration is retained, including the default full-catalog candidate strategy.

Downloads include wheel, sdist, full source ZIP and SHA256SUMS, built from the tested commit. This patch changes publication handling and the reported package version; routing behavior is the same as 0.4.0. Live Jev accuracy, billed cost and model-driven host task success remain unmeasured.
