# Remotion explainer

Inspect the installed Remotion version and current official documentation before using APIs.
Use a registered Composition with explicit width, height, FPS and duration. Drive animation from useCurrentFrame and interpolate rather than wall-clock time or CSS animations.
Use only owned or licensed assets. Do not bundle font binaries unless redistribution is explicitly permitted and requested.
Pin compatible Remotion package versions. Render an MP4 and inspect representative frames for clipping and readability.
Record whether the artifact was rendered by Remotion, another renderer, or is only a storyboard. Never label a conceptual animation as a live product recording.
